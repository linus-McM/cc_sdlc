`build sync`, commit `build(archify-stage-documentation): <step>`. Tests never call the real
`node`, `npx` or Archify. `tests/conftest.py` gains `monkeypatch.setenv("SDLC_DOCS", "off")` in
the `repo` fixture (every existing test runs with docs off and unchanged) and a `docs_tools`
fixture that deletes that env var, prepends a temp `bin/` to a bare PATH (plus git's directory,
`/usr/bin`, `/bin`) holding executable `node` and `npx` shell scripts that append their argv to
`bin/calls.log`, sets `HOME` and `CLAUDE_CONFIG_DIR` to temp dirs, and pre-creates
`$CLAUDE_CONFIG_DIR/skills/archify/bin/archify.mjs` (one line) plus
`skill-release.json` with `{"version": "2.17.0-dev.1"}` (a `FakeDocs` object exposes `.bin`,

`*/archify.mjs deliver <type> <in> <out> --quality showcase --json` exits 1 printing
`composition error: node budget` to stderr when `<in>` contains `"fail": true`, otherwise writes
`<!doctype html><title>fake</title>` to `<out>` and prints
`{"status":"pass","specification":{"sha256":"<sha of in>","bytes":N},"artifact":{"sha256":"<sha of out>","bytes":N},"checks":{"passed":9,"total":9},"errors":0,"warnings":0}`;

## Risks
- Import cycle: `knowledge` imports `docs` for the step; `docs` must never import `knowledge` at
  module level (only inside `archify_present`/`install_archify` for `StepSkipped`/`ran`). Riskiest
  step is 7: it changes `bootstrap`'s loop (present-check may raise) and every existing bootstrap
  test's expected step list and ignore file; run the whole knowledge suite before green.
- `testing.review` signature change (step 4) touches `cli.py` and `deploy.pr_body`; grep callers.
- Fake-tool PATH: the docs fixture strips PATH; `git`, `sh`, `sed`, `sha256sum`/`shasum` must be
  reachable (`/usr/bin`, `/bin`, git's dir), as the `knowledge` fixture already does.
- Receipt parsing: real `deliver --json` may print non-JSON lines first; parse the last line
  that decodes as an object, else fail verbatim with the tail.
- Pre-commit hooks rewriting HTML (step 10); without the exclude the committed artifact's sha
  drifts from the receipt. Gate uses `source_digest`, so a drift would not break gates, only the
  receipt's truth.
- Stage docs directory sits under `sdlc/`, so `build.sync` already treats it as sdlc-owned; no
  plan listing needed per file.
- `p.feature(root, None)` picks the most recent feature; `docs render maintain` must not touch it.
- Options rejected: generating the Archify JSON in Python from the artifact (loses the reading
  that makes the diagram useful; Claude authors, Python gates); rendering inside hooks (10-second
  timeouts, Node startup); Claude Code Artifact publishing (closed in intent); gating on
  `visual-check` (Chrome dependency, closed in spec); a `[docs]`-owned `SessionStart` line
  (bootstrap step list already prints it).
