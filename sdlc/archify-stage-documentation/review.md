- Nit: scripts/sdlc/docs.py:103 `archify_present` reports `present` from the skill directory alone, so a Node-less machine sees a healthy bootstrap step and a refused `render`. Accepted as is: the present-check runs on every session start and must not spawn a process on a healthy project (`test_bootstrap_healthy_project_makes_no_calls`); `render` and `open` name the Node problem verbatim.
